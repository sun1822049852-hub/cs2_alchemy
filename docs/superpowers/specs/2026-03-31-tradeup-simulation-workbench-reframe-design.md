# 汰换模拟工作台重构设计稿

日期：2026-03-31  
状态：已完成脑暴确认，待评审  
说明：本稿用于取代旧版 `汰换模拟` 页面骨架设计；旧稿中的搜索、解析、左右联动、保存等业务逻辑继续沿用，重点重构页面结构、信息层级与保存语义。

## 1. 背景

现有 `汰换模拟` 首版实现已经具备基础逻辑，但页面观感与工作流都不理想：

- 视觉主次失衡，顶部主卡与配置区占用过多空间
- 下方结果区出现大面积亮底，与全局深色主题断层明显
- 用户难以快速理解“目标产物”“锚定物品”“当前编辑结果”之间的关系
- 保存配方视图与选材工作台没有被清晰分层

本次重构不重写核心解析链路，而是围绕“找配方、看联动、快速回到上次锚定状态”重新定义工作台结构。

## 2. 产品目标

### 2.1 首要目标

- 让页面一眼看懂当前处于“选配方”还是“编辑配方”
- 让用户在宽屏下稳定看到 `左产物 / 右材料` 的主工作区
- 让“编辑哪张左侧卡，哪张就成为当前锚定物品”的规则直观可感知
- 让已保存配方能快速重载回上次工作状态

### 2.2 非目标

- 不改变现有解析接口和磨损联动核心算法
- 不把模拟页接入炼金执行队列
- 不引入新的收益、概率、库存联算功能
- 不在本轮实现新的辅料复杂编辑器，只保留已定的收藏品锚定语义

## 3. 已确认结论

### 3.1 页面不是多页跳转，而是单工作台双模式

`汰换模拟` 保持为一个导航页面，但页面内部切为两种模式：

- `已保存配方`
- `选材页面`

这两个模式只是同一工作台的两种视图，不新增子页面，不新增侧边栏工作区，不做多列并排。

### 3.2 已保存配方模式

该模式只负责“选择要编辑的配方”，不负责展开完整左右联动工作区。

展示形式：

- 使用卡片墙或多行卡片列表展示已保存配方
- 每张卡片展示：
  - 目标产物图与名称
  - 当前锚定物品名称
  - 当前锚定绝对磨损
  - 已选辅料收藏品摘要
- 点击卡片后：
  - 切换到 `选材页面`
  - 将该配方载入当前工作台

### 3.3 选材页面模式

该模式是主工作台，负责真正的查看、精修与保存。

结构固定为：

- 顶部模式切换条
- 顶部工作台摘要条
- 下方主工作区

主工作区固定为：

- 左侧：目标产物区
- 右侧：材料区

空间足够时始终优先保持左右双列，不再退回当前这种“上方配置 + 下方大结果板”的割裂结构。

## 4. 领域语义重定义

### 4.1 目标产物

`目标产物` 是创建这条模拟配方时的入口物品。

它的职责只有两个：

- 决定这条配方从哪个具体物品出发
- 决定需要展开哪个收藏品链路

它不是持续唯一驱动全局的“主卡”。

### 4.2 锚定物品

`锚定物品` 属于该目标产物链路展开后的左侧目标产物子集。

规则如下：

- 左侧所有可编辑目标产物都可以成为锚定物品
- 用户精修哪一张左侧产物卡，这张卡立刻成为新的锚定物品
- 当前锚定物品负责驱动整组重算

### 4.3 辅料收藏品

右侧材料不直接保存为单张物品快照，而是保存“当前采用哪些辅料收藏品约束材料展开”的锚定条件。

保存后下次载入时，前端基于：

- `目标产物`
- `锚定物品`
- `锚定绝对磨损`
- `辅料收藏品选择`

重新快速构建整页结果。

## 5. 页面布局设计

### 5.1 顶部模式切换条

工作台顶部第一层只保留两个模式按钮：

- `已保存配方`
- `选材页面`

要求：

- 当前模式高亮明确
- 样式更接近 segment / tab，不再混入普通功能按钮堆
- 不与保存按钮、搜索按钮混排成一堆

### 5.2 工作台摘要条

模式切换下方增加一条紧凑摘要条，用于承接当前上下文。

摘要条至少展示：

- 当前目标产物摘要
- 当前锚定物品摘要
- 当前锚定绝对磨损
- 当前配方保存状态：
  - 已保存
  - 有未保存修改

右侧放功能按钮：

- `覆盖保存`
- 可选的“重新选择目标产物”入口

这条摘要条取代旧版的大主卡职责，但不会占据过高空间。

### 5.3 选材页面主工作区

工作区采用 `左产物 / 右材料` 双列。

左列顶部放一个虚线参考框：

- 显示当前目标产物
- 作为重新选择目标产物的入口
- 点击后打开全量皮肤搜索器

左列主体：

- 展示该链路下的全部可编辑目标产物
- 当前锚定物品在视觉上高亮

右列主体：

- 展示当前锚定物品驱动出的全部只读材料
- 不允许直接编辑绝对磨损

### 5.4 已保存配方视图

该视图不展示左右双列主工作区，而是用更轻的配方卡片墙表达“当前有哪些样例”。

点击某条已保存配方后：

1. 设置当前活动配方
2. 切换到 `选材页面`
3. 自动根据保存字段重算

## 6. 卡片视觉规则

### 6.1 统一参考目标预测卡的视觉语言

本次重构的卡片风格参考现有“目标预测”卡：

- 深色主题背景下的统一卡片体系
- 明确的图片区、标题区、状态区、磨损区
- 控件与说明在卡片内部紧凑排列

禁止继续沿用当前版本的大面积亮白底结果板。

### 6.2 左侧产物卡

每张左侧产物卡显示：

- 物品图
- 物品名
- 收藏品 / 稀有度
- 当前角色标记：
  - 目标入口
  - 当前锚定
  - 普通候选
- 绝对磨损输入框
- 自动匹配的磨损品级标签
- 磨损条

当前锚定卡必须有明显高亮：

- 边框强调
- 顶部状态条或角标
- 可选轻发光

### 6.3 右侧材料卡

每张右侧材料卡显示：

- 物品图
- 物品名
- 收藏品 / 稀有度
- 锁定标记
- 绝对磨损值
- 磨损品级标签
- 磨损条
- 只读说明

右侧卡片不提供可编辑输入框。

### 6.4 信息密度控制

- 卡片主信息只保留必要字段
- 长解释性文字缩减为短标签或短说明
- 卡片高度尽量统一
- 左右两列视觉重量要接近，避免左侧重、右侧轻或反之

## 7. 保存语义

### 7.1 保存内容

保存一条配方时，仅保留可用于快速恢复的关键状态：

- `id`
- `name`
- `target_item`
- `active_anchor_item`
- `active_anchor_abs_wear`
- `selected_material_collections`
- `updated_at`

### 7.2 不保存的内容

不保存整组完整解析结果，例如：

- 全量左侧目标产物展开结果
- 全量右侧材料结果
- 一次性警告列表快照

理由：

- 页面重载时应根据最新规则重新解析
- 避免旧缓存结果与新解析逻辑不一致
- 减少持久化体积与状态污染

### 7.3 打开流程

点击一条已保存配方后：

1. 恢复 `target_item`
2. 恢复 `active_anchor_item`
3. 恢复 `active_anchor_abs_wear`
4. 恢复 `selected_material_collections`
5. 调用现有解析流程重新生成左产物与右材料
6. 切到 `选材页面`

### 7.4 编辑后的未保存状态

用户修改左侧任意产物绝对磨损后：

- 当前被编辑卡成为新的锚定物品
- 页面进入 `dirty` 状态
- 顶部摘要条显示“未保存修改”
- 只有点击 `覆盖保存` 才真正写回 preset

## 8. 交互流程

### 8.1 新建配方

1. 切到 `选材页面`
2. 点击左上虚线参考框
3. 搜索并选择一个目标产物
4. 前端根据该目标产物展开左侧产物集合
5. 自动读取相应材料链路，填充右侧材料区
6. 默认选定一张初始锚定物品并完成首轮解析

### 8.2 精修锚定

1. 用户编辑左侧任意产物卡的绝对磨损
2. 该卡成为新的当前锚定物品
3. 所有左侧产物和右侧材料一起重算
4. 顶部摘要同步显示新的当前锚定信息

### 8.3 保存当前配方

1. 用户点击 `覆盖保存`
2. 前端写入：
   - 当前锚定物品
   - 当前锚定绝对磨损
   - 当前辅料收藏品选择
3. 清除 `dirty` 状态

### 8.4 切换已保存配方

1. 用户切到 `已保存配方`
2. 点击一张配方卡
3. 当前工作台切换到该配方
4. 页面进入 `选材页面`
5. 自动恢复并重算

## 10. 验收标准

重构完成后，至少满足以下验收口径：

### 10.1 视觉与结构

- 一眼能分辨当前处于 `已保存配方` 还是 `选材页面`
- `选材页面` 中左产物、右材料区块边界清晰
- 当前锚定物品一眼可识别
- 页面整体不再出现强烈的黑白割裂感
- 结果区成为视觉主角，而不是被顶部表单抢走注意力

### 10.2 交互

- 点击已保存配方可正确载入到 `选材页面`
- 点击虚线参考框可重新选择目标产物
- 编辑左侧任意产物绝对磨损后，整组联动正常
- 右侧材料保持只读
- 覆盖保存后，下次载入可以快速恢复上次锚定状态与辅料收藏品选择

### 10.3 回归

- 现有搜索 API、resolve API 继续可用
- 现有保存 / 读取 preset 流程继续可用
- 不影响 `craftPage` 和已有 predictor 相关功能
