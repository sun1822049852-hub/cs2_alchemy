# 产物预测抽屉参考图对齐设计

> 状态：已在 companion 样稿中确认
> 日期：2026-03-28
> 范围：仅 `craft predictor drawer`
> 类型：前端视觉与布局对齐，不改后端预测协议

## 目标

在不改动产物预测数据来源、分组逻辑与抽屉基本交互模型的前提下，让当前 `产物预测` 抽屉的视觉与信息排布向魔尊确认的参考图靠拢。

本次改动只解决以下问题：

- 当前抽屉内部卡片信息堆叠感过重
- 旧版右侧分组导航与参考图风格冲突
- 旧版卡片保留了无意义的价格占位
- 黄色拉手过细、过长，且视觉上像旧式侧边 rail
- 抽屉展开时有“向下沉”的压感，不符合本次目标
- 顶部状态条 `当前已预测 X 个可产出物品` 干扰参考图式的结果阅读

本次明确不做以下事项：

- 不改 `POST /api/craft/predict-outcomes` 契约
- 不改预测分组算法和概率计算
- 不新增折叠分组、筛选、排序、收藏等新交互
- 不重做抽屉外部的候选区、执行区、队列逻辑
- 不把抽屉改成整页或全屏模式

## 参考来源

### 当前项目

- `node_sidecar/ui/index.html`
- `node_sidecar/ui/styles.css`
- `node_sidecar/ui/app.js`

当前版本的抽屉特征：

- 底部 overlay drawer，默认收起
- 右侧细长黄色拉手
- 顶部包含状态条
- 主体为 `列表 + 右侧分组导航`
- 结果卡片为横向信息卡，右下角保留价格占位壳体

### 参考图

魔尊提供的参考图核心特征：

- 黑灰底结果面板
- `模拟结果` 作为主标题区
- 收藏品分组以纯内容流纵向排列
- 每组内部使用三列紧凑缩略卡
- 卡片强调磨损条、磨损标签、概率标签、名称
- 不显示价格
- 拉手更像短而厚的 tab，不是长条 rail

## 约束

### 功能约束

- 保留现有抽屉开关模型：隐藏时露出右侧把手，打开时抽屉覆盖候选区下半部分
- 保留现有结果分组来源与每个 outcome 的基础字段渲染能力
- 保留 `id` 与现有 JS 绑定点，除非新增节点更适合作为局部容器

### 结构约束

- 不移除 `craftPredictorStage`、`craftPredictorPanel`、`craftPredictorDrawer`
- 不把抽屉重新改回独立右侧栏
- 不在 drawer 内继续保留第二列导航
- 不增加新的全局布局依赖

### 作用域护栏

- 允许修改作用域仅限：
  - `#craftPredictorPanel`
  - `#craftPredictorDrawer`
  - `#craftPredictorList`
  - `#craftPredictorHandle`
  - `node_sidecar/ui/app.js` 中 predictor 渲染函数
- 新样式必须局限在 `craft-predictor-*` 作用域内
- 禁止借由全局 `.card`、`.panel`、`button` 覆写完成本次视觉迁移

## 确认后的设计结论

## 一、抽屉骨架

抽屉仍然是候选区下半部分的 overlay，但视觉上不再强调“玻璃感边框盒子”，而是更接近参考图里的平直黑色结果面板。

骨架调整如下：

- 保留标题 `产物预测`
- 删除旧状态条 `当前已预测 X 个可产出物品`
- 抽屉内部头部改为：
  - 主标题：`模拟结果`
  - 副标题：当前配方说明，例如 `#1 | 平均相对磨损 ...`
  - 右侧折叠/收起图标
- 内容区改为纯纵向滚动流，不再拆成 `列表 + 右导航`

## 二、拉手形态

旧版拉手的问题是：

- 太细长
- 更像“抽屉轨道”
- hover / 展开状态容易让人感到压入或下沉

新拉手方向：

- 改成更短、更厚的金色 tab
- 形状更接近参考图右侧小把手
- 保持右边缘露出
- 展开/收起只表现为箭头方向变化与 drawer 的横向平移
- 取消任何会造成“下沉感”的位移、阴影加深或整体 Y 轴偏移

## 三、内容结构

删除右侧 `craftPredictorNav` 后，drawer 主体只保留一个滚动内容流。

每个收藏品分组结构为：

1. 分组标题行
2. 该组结果卡片网格

标题行内容：

- 左侧：收藏品名称 + 数量，如 `狩猎运动收藏品(4)`
- 右侧：轻量箭头/提示符，作为视觉呼应，不承担单独导航职责

## 四、结果卡片

结果卡片不再使用当前横向 media card，而改成更贴近参考图的紧凑竖卡。

每张卡片包含：

- 顶部图片区
- 左上磨损标签
- 右上概率标签
- 图片下方磨损数值
- 一条横向磨损色带
- 底部名称

明确删除：

- 价格占位框
- 旧的 footer meta + price 双栏结构
- 冗余 chip 行堆叠

保留信息优先级：

1. 图片
2. 磨损标签
3. 概率
4. 预测磨损数值
5. 磨损色带
6. 名称

若存在额外信息如 `mapped_skin_missing`，不再挤入卡片主布局，可作为简短次级提示或在缺失时降级展示。

## 五、栅格策略

为贴近参考图，本次优先采用三列紧凑网格：

- 常规宽度：`repeat(3, minmax(0, 1fr))`
- 空间不足时再自然降为两列
- 卡片间距应较当前更紧，减少桌面卡片感

这意味着抽屉在视觉上更像“结果图库”，而不是“信息表格式详情卡片列表”。

## 六、动效结论

本次只保留必要动效：

- drawer：右向左平移展开 / 收起
- handle arrow：方向翻转
- hover：轻微亮度与边框反馈

明确不做：

- 整体 Y 轴下压
- 像按钮按下那样的 inset 视觉
- 会让抽屉产生“掉下去”错觉的阴影变化

## DOM / 渲染调整

### 保留

- `#craftPredictorStage`
- `#craftPredictorPanel`
- `#craftPredictorHandle`
- `#craftPredictorDrawer`
- `#craftPredictorList`

### 删除或停用

- 删除 `#craftPredictorStatus` 的可见展示职责
- 停用 `#craftPredictorNav` 作为渲染目标
- 结果卡片内移除 `craft-predictor-outcome-price-slot`

### JS 渲染方向

`renderCraftPredictorPanel()` 需要改成：

- 不再写入顶部状态条文案
- 不再渲染右侧导航按钮
- 分组头改为“标题 + 轻箭头”
- outcome card 改为竖向缩略卡结构
- 价格相关 DOM 完全不创建

## 样式方向

样式基调采用：

- 深炭黑面板
- 暖白正文
- 金黄拉手与轻点缀
- 紫色稀有度边条
- 蓝色概率 badge
- 低圆角紧凑卡片

避免：

- 过强蓝色科技感
- 大块玻璃拟态
- 过厚卡片描边
- 大留白桌面 dashboard 感

## 测试要求

至少覆盖以下验证点：

1. 抽屉不再依赖右侧导航布局
2. 抽屉渲染结果列表时不再生成价格占位节点
3. 顶部旧状态条不再作为主要显示块
4. 新拉手使用短 tab 样式，而非旧细长 rail
5. 结果网格在常规宽度下为三列紧凑布局
6. 抽屉展开动画仍为横向 slide，不引入纵向下沉位移

## 实施边界

本次实现预计只需要修改：

- `node_sidecar/ui/index.html`
- `node_sidecar/ui/styles.css`
- `node_sidecar/ui/app.js`
- 与之对应的 UI 测试文件

不需要改动后端 service、route 或数据库逻辑。

## 验收标准

当以下条件同时满足时，视为本劫已破：

- 打开抽屉后第一眼更接近 companion 定稿，而非旧版横向信息卡
- 抽屉内不存在价格占位与右侧收藏品导航
- 顶部不再出现 `当前已预测 X 个可产出物品`
- 右侧把手变成短 tab，视觉更接近参考图
- 展开与收起只表现为横向滑出 / 滑回，不再产生下沉感
- 现有预测数据仍能正确分组渲染
