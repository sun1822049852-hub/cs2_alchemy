# Development File Logging

The environment variable `CS2_DEV_FILE_LOG=1` is the only enable switch. Every other value, including an unset variable, keeps file logging disabled for end users. Existing console output remains unchanged. Enabled file logs use structured daily JSONL under `PATHS.LOG_DIR/dev`, redact credential and session material, retain only the current local date and previous two local dates, and fail open without changing application behavior. Existing specialized Craft, Guard, capture and artifact logs remain independently owned and unchanged.
